## 재현 및 후속 조치

`questions.csv`와 `clarification_scenarios.csv`는 각 평가 실행 전 고정한 입력이다. `active_corpus.json`은 당시 승인 후보의 원문과 ID, `retrieval_raw.csv`와 `clarification_raw.csv`는 원시 관측이다. 제품 및 DB 상태가 바뀌면 원본 결과를 덮어쓰지 말고 별도 경로에서 실행해야 한다. 스크립트는 localhost 시연 DB/KURE와 기존 Docker 컨테이너를 사용하며 실행 중 Generation 변경 시 검색 측정을 중단한다. 사용자 계정 쿠키나 키를 읽지 않는다.

후속 평가는 독립 평가자가 각 문항의 관련 Claim 전체와 무관 Claim을 블라인드 판정하고 명확·모호 의도를 검증한 다음, raw RRF 후보를 안전하게 관측할 수 있는 평가 경로와 실제 UI의 선택·종료를 포함해야 한다. 신규 데이터·사용자 질문에 대한 일반화, 정밀도와 의미 검증기의 정확도는 이 결과로 결론 내릴 수 없다.
