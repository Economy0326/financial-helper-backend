# R4-C 합성 검색 안전 회귀

2026-11-17에 일회성 PostgreSQL 16과 분리된 CPU KURE-v2 인덱스로 기존 R4-B2 합성 평가를 한 번 재실행했다. 실제 KURE, 제품 활성 Generation, PostgreSQL과 제품 RRF(k=60)를 사용했다. 공식 원문이나 외부 AI는 사용하지 않았다. 변경 전 R4-B2 결과는 `r4b2-live-hybrid-evaluation-2026-11-17.md`에 보존한다.

승인 Claim 8개, 양성 질문 17개, 무근거 질문 2개다. P@3의 분모는 항상 3이며 양성 사례의 매크로 평균이다. 정답은 자체 작성한 합성 기준으로 실제 사용자 정확도를 보장하지 않는다.

| 방식 | Recall@3 | Precision@3 | NDCG@3 |
| --- | ---: | ---: | ---: |
| PostgreSQL | 0.8235 | 0.3137 | 0.8235 |
| KURE | 1.0000 | 0.3725 | 0.9349 |
| 원시 RRF | 1.0000 | 0.3725 | 0.9783 |
| 사용자 근거 채택 | 0.7059 | 0.2353 | 0.7059 |

무근거 2개에 원시 KURE와 원시 RRF는 각각 2개씩 결과를 반환했지만 사용자 근거 채택은 0개였다. `기존`은 키워드 [B, A], KURE [A, B, E], 원시 RRF [B, A, E]였고 사용자에게는 `NEEDS_CLARIFICATION`과 빈 근거가 반환됐다. 채택 점수는 R4-B2 최종 실행의 0.8235 / 0.3137 / 0.8235보다 낮다. 단일 검색어에 여러 Claim이 맞으면 유보하기 때문에 명확한 단일 단어 질문도 놓칠 수 있다. 반대로 후보가 하나인 모호한 질문의 의미를 판별하지는 못한다.

실모델 실행 후 문장부호가 검색어 앞에 있는 경우의 단어 분리를 보완했다. 해당 보완은 별도 단위 테스트 대상이며 위 실모델 점수는 보완 전 실행값이다. AI 설명 생성·검증과 외부 AI 정확도는 이 평가에 포함하지 않았다.
